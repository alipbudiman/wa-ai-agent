# WhatsApp AI Agent Command Menu

Here are the available commands you can use to interact with the WhatsApp AI Agent:

- /help - Displays available commands.
- /ping - Responds with 'Pong!' to test connectivity.
- /about - Shows AI agent architecture and capability overview.
- /message-pending - Retrieves the current pending on-hold message for review.
- /send - Sends a pending message on hold to the specified number.
- /unsend - Cancels and removes the current pending on-hold message.
- /file-pending - Retrieves the current pending on-hold file for review.
- /file-send - Sends a pending file on hold to the specified number.
- /file-unsend - Cancels and removes the current pending on-hold file.
- /select-providers - Selects the AI provider to use for responses.
- /contact-info - Retrieves information about a specific contact.
- /code - Delegate task direct to Agent Code
- /research - Initiate a research query using the AI agent.
- /auto-reply-config - Configure auto-reply AI settings.
- /ai-group-interaction-config - Configure AI group interaction settings.
- /ollama-config - Configure Ollama LLM provider settings.
- /openrouter-config - Configure OpenRouter LLM provider settings.
- /nvidia-config - Configure Nvidia LLM provider settings.
- /anthropic-config - Configure Anthropic LLM provider settings.
